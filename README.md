# Paint Can Calculator

A simple Python program that estimates the number of paint cans required to paint a wall. The program asks the user to enter the wall's width and height, calculates the total wall area, and determines the minimum number of paint cans needed. It assumes that **one can of paint covers 4 square meters** and uses Python's `math.ceil()` function to round up the result, ensuring there is enough paint to cover the entire wall.

## Features

* Accepts user input for wall width and height.
* Calculates the total wall area.
* Assumes one paint can covers **4 square meters**.
* Uses `math.ceil()` to round up the number of cans required.
* Demonstrates the use of functions, mathematical calculations, and user input in Python.

## How to Run

1. Make sure Python 3 is installed.
2. Run the script:

   ```bash
   python paint_can_calculator.py
   ```
3. Enter your name, the wall width, and the wall height when prompted.
